# HomeLight

Система умного домашнего освещения с управлением несколькими зонами на базе адресной светодиодной ленты WS2812B и микроконтроллера WEMOS.

## Описание проекта

Проект предназначен для создания гибкой системы освещения в различных зонах помещения с использованием программируемых светодиодов. Каждая зона может иметь индивидуальные настройки цвета, яркости и эффектов.

## Оборудование

- **Микроконтроллер**: WEMOS (на базе ESP8266/ESP32)
- **Светодиодная лента**: WS2812B, 60 светодиодов на метр
- **Дополнительно**: 
  - Блок питания 5V
  - Резистор 330-470 Ом (для защиты данных)
  - Конденсатор 1000µF (для стабилизации питания)

## Возможности

- 🌈 Управление цветом (RGB)
- 💡 Регулировка яркости
- ✨ Предустановленные световые эффекты
- 🏠 Разделение на несколько зон освещения
- 📱 Возможность удалённого управления (через Wi-Fi)
- ⚙️ Гибкая настройка параметров

## Установка и подключение

### Схема подключения

```
WEMOS          WS2812B
-----          -------
D1 (GPIO5)  ->  DIN (Data In)
5V          ->  VCC
GND         ->  GND
```

### Необходимые библиотеки

Для работы проекта потребуются следующие библиотеки:

- [FastLED](https://github.com/FastLED/FastLED) или [Adafruit NeoPixel](https://github.com/adafruit/Adafruit_NeoPixel)
- Библиотеки для Wi-Fi соединения (встроены в Arduino ESP8266/ESP32)

## Использование

1. Подключите светодиодную ленту к контроллеру согласно схеме
2. Загрузите прошивку в микроконтроллер
3. Настройте параметры зон в конфигурационном файле
4. Подключитесь к сети Wi-Fi
5. Управляйте освещением через веб-интерфейс или мобильное приложение

## Конфигурация зон

Проект спроектирован с учетом гибкости и масштабируемости. Все названия зон, их количество, число светодиодов и другие количественные показатели являются редактируемыми параметрами, а не фиксированными значениями.

### Принципы проектирования

- **Относительность параметров**: Все числовые значения (количество светодиодов, номер пина, идентификаторы зон) вынесены в конфигурационные константы и могут быть легко изменены
- **Масштабируемость**: Система поддерживает произвольное количество зон освещения
- **Гибкость настройки**: Параметры каждой зоны настраиваются индивидуально

### Пример конфигурации для конкретного проекта

Ниже приведен пример настройки для трехзонной системы освещения:

```cpp
// === НАСТРАИВАЕМЫЕ ПАРАМЕТРЫ ===

// Общее количество светодиодов в системе
// Зона 1: 4 ленты × 4м × 60 светодиодов/м = 960 светодиодов
// Зона 2: 4 ленты × 5м × 60 светодиодов/м = 1200 светодиодов
// Зона 3: 4 кольца × 12 светодиодов = 48 светодиодов
// Итого: 2208 светодиодов
#define TOTAL_LEDS 2208

// Количество зон освещения
#define NUM_ZONES 3

// Пин подключения данных ленты (для каждого WEMOS)
#define LED_PIN D1

// Конфигурация зон
struct ZoneConfig {
  const char* name;      // Название зоны (редактируемое)
  uint16_t startLed;     // Начальный светодиод зоны
  uint16_t ledCount;     // Количество светодиодов в зоне
  bool hasDisplay;       // Наличие дисплея для часов
};

// Пример настройки зон для проекта HomeLight
ZoneConfig zones[NUM_ZONES] = {
  {"Барная стойка", 0, 960, true},    // Зона 1: 4 параллельные ленты по 4м (960 светодиодов), с дисплеем
  {"Над диваном", 960, 1200, false},  // Зона 2: 4 полосы по 5м (1200 светодиодов)
  {"Центральная", 2160, 48, false}    // Зона 3: 4 кольца по 12 светодиодов (48 светодиодов)
};

// === КОНЕЦ НАСТРАИВАЕМЫХ ПАРАМЕТРОВ ===
```

> **Важно**: Все числовые значения в примере (количество лент, длина, плотность светодиодов, число колец) приведены для иллюстрации конкретной конфигурации и могут быть заменены на любые другие. Система спроектирована так, что все параметры являются редактируемыми величинами.

### Детальное описание зон проекта

#### Зона 1 - Барная стойка
- **Конфигурация**: 4 параллельные адресные ленты WS2812B
- **Длина каждой ленты**: 4 метра
- **Плотность светодиодов**: 60 шт/метр
- **Общее количество светодиодов**: 4 × 4м × 60 = 960 светодиодов
- **Особенности**: 
  - Возможность управления каждой лентой отдельно или совместно
  - Выделенный контроллер WEMOS для этой зоны
  - Интегрированный дисплей для отображения часов
- **Гибкость**: Названия, количество лент, длина и плотность светодиодов - редактируемые параметры

#### Зона 2 - Над диваном
- **Конфигурация**: 4 световые полосы адресных светодиодов WS2812B
- **Длина каждой полосы**: 5 метров
- **Плотность светодиодов**: 60 шт/метр
- **Общее количество светодиодов**: 4 × 5м × 60 = 1200 светодиодов
- **Особенности**: Равномерная подсветка большой площади
- **Гибкость**: Все количественные показатели могут быть изменены под конкретную задачу

#### Зона 3 - Центральная
- **Конфигурация**: 4 декоративных кольца
- **Количество светодиодов в кольце**: 12 адресных светодиодов WS2812B
- **Общее количество светодиодов**: 4 × 12 = 48 светодиодов
- **Особенности**: Компактные световые элементы для акцентного освещения
- **Гибкость**: Количество колец и светодиодов в каждом кольце - настраиваемые величины

### Рекомендации по настройке

1. **Определение зон**: Разделите пространство на логические зоны (например, "Рабочий стол", "Полка", "Подсветка ТВ")
2. **Расчет светодиодов**: Подсчитайте количество светодиодов для каждой зоны
3. **Настройка в коде**: Внесите данные в массив `zones[]`
4. **Тестирование**: Проверьте работу каждой зоны отдельно

> **Важно**: Все числовые значения в примере (60 светодиодов, 2 зоны, 30 светодиодов на зону) приведены для иллюстрации и могут быть заменены на любые другие в соответствии с вашей конфигурацией.
