# HomeLight

Распределенная система умного домашнего освещения на базе **ESP32** и адресных светодиодных лент **WS2812B**. Проект реализует управление освещением в трех независимых зонах, где каждая зона управляется своим собственным микроконтроллером ESP32.

## 📋 Описание проекта

Проект предназначен для создания гибкой системы освещения в различных зонах помещения с использованием программируемых светодиодов. Каждая зона может иметь индивидуальные настройки цвета, яркости и эффектов.

### Особенности архитектуры
- **Децентрализованное управление**: Каждая зона имеет свой независимый контроллер ESP32.
- **Независимость**: Выход из строя или перезагрузка одной зоны не влияет на работу остальных.
- **Сетевая синхронизация**: Зоны объединяются в единую экосистему через Wi-Fi (MQTT/HTTP) для запуска общих сценариев.
- **Масштабируемость**: Легкое добавление новых зон или изменение параметров существующих.

> **Важно**: Все названия и количественные показатели в проекте носят относительный характер и употребляются для простоты понимания. В самой реализации это должны быть редактируемые величины с изменяемыми количественными данными.

## 🛠 Оборудование

Для реализации проекта используются следующие компоненты:

| Компонент | Количество | Назначение |
| :--- | :--- | :--- |
| **ESP32 DevKit V1** | 3 шт. | Контроллеры для каждой из 3-х зон |
| **Лента WS2812B 60 LED/m** | ~21.5 м | Основное освещение (ленты) |
| **Кольца WS2812B** | 4 шт. | Декоративное освещение (Зона 3) |
| **Дисплей (OLED/e-Paper)** | 1 шт. | Отображение времени (Зона 1) |
| **Блок питания 5V** | 3 шт. | Питание лент и контроллеров (расчет по току) |
| **Резистор 330-470 Ом** | 3 шт. | Защита линий данных |
| **Конденсатор 1000µF** | 3 шт. | Стабилизация питания |

## 💡 Возможности системы

- 🎨 **RGB Подсветка**: 16 миллионов цветов, настройка яркости.
- 🌈 **Эффекты**: Динамические эффекты (радуга, бегущие огни, дыхание и т.д.).
- ⏰ **Часы**: Отображение времени в зоне бара.
- 📱 **Управление**: Через веб-интерфейс, мобильное приложение или голосовые ассистенты (через интеграцию).
- 🔗 **Сценарии**: Синхронизированные эффекты между всеми зонами.
- ⚙️ **Гибкая настройка**: Все параметры редактируемые.

## 🏠 Конфигурация зон

Общее расчетное количество светодиодов в системе: **2208 LED**.

### Зона 1: Барная стойка
- **Контроллер**: ESP32 (выделенный)
- **Нагрузка**:
  - 4 параллельные светодиодные ленты.
  - Длина каждой ленты: **4 метра**.
  - Плотность: 60 диодов/метр.
  - Итого в зоне: **960 светодиодов**.
- **Дополнительно**: Дисплей для отображения часов.
- **Режимы работы**: Управление каждой лентой отдельно или всеми совместно.

### Зона 2: Над диваном
- **Контроллер**: ESP32 (выделенный)
- **Нагрузка**:
  - 4 световые полосы.
  - Длина каждой полосы: **5 метров**.
  - Плотность: 60 диодов/метр.
  - Итого в зоне: **1200 светодиодов**.

### Зона 3: Центральная зона
- **Контроллер**: ESP32 (выделенный)
- **Нагрузка**:
  - 4 адресных кольца.
  - Количество диодов в кольце: **12 штук**.
  - Итого в зоне: **48 светодиодов**.

## 🔌 Установка и подключение

### Схема подключения (для каждой зоны)

```
ESP32          WS2812B
-----          -------
GPIOxx      ->  DIN (Data In)
5V          ->  VCC (+ через блок питания)
GND         ->  GND
```

> **Примечание**: Для Зоны 1 дополнительно подключите дисплей к соответствующим пинам ESP32 (I2C: SDA/SCL или SPI).

### Необходимые библиотеки

Для работы проекта потребуются следующие библиотеки:

- [FastLED](https://github.com/FastLED/FastLED) или [Adafruit NeoPixel](https://github.com/adafruit/Adafruit_NeoPixel) - управление светодиодными лентами
- [WiFi](https://github.com/espressif/arduino-esp32/tree/master/libraries/WiFi) - встроенная библиотека для Wi-Fi соединения
- [MQTT](https://pubsubclient.knolleary.net/) - для сетевой синхронизации зон (опционально)
- Библиотека для дисплея (например, [Adafruit SSD1306](https://github.com/adafruit/Adafruit_SSD1306)) - для Зоны 1

## 🚀 Использование

1. **Подготовка оборудования**:
   - Подключите светодиодные ленты к контроллеру ESP32 согласно схеме
   - Подключите дисплей в Зоне 1
   - Обеспечьте стабильное питание 5V

2. **Настройка ПО**:
   - Установите необходимые библиотеки в Arduino IDE или PlatformIO
   - Откройте проект для каждой зоны
   - Настройте параметры в конфигурационном файле (`config.h`):
     - PIN подключения ленты
     - Количество светодиодов
     - Название зоны
     - Параметры сети Wi-Fi
     - Адрес MQTT-брокера (если используется)

3. **Загрузка прошивки**:
   - Загрузите прошивку в каждый ESP32 через USB
   - Дождитесь подключения к Wi-Fi

4. **Управление**:
   - Подключитесь к веб-интерфейсу устройства
   - Или используйте MQTT-клиент для управления
   - Настройте сценарии освещения

## ⚙️ Конфигурация зон

Проект спроектирован с учетом гибкости и масштабируемости. Все названия зон, их количество, число светодиодов и другие количественные показатели являются редактируемыми параметрами, а не фиксированными значениями.

### Принципы проектирования

- **Относительность параметров**: Все числовые значения (количество светодиодов, номер пина, идентификаторы зон) вынесены в конфигурационные константы и могут быть легко изменены
- **Масштабируемость**: Система поддерживает произвольное количество зон освещения
- **Гибкость настройки**: Параметры каждой зоны настраиваются индивидуально
- **Независимость зон**: Каждая зона работает на своем ESP32 с индивидуальной прошивкой

### Пример конфигурации для конкретного проекта

Ниже приведен пример настройки для трехзонной системы освещения:

```cpp
// === НАСТРАИВАЕМЫЕ ПАРАМЕТРЫ ===

// Общее количество светодиодов в системе
// Зона 1: 4 ленты × 4м × 60 светодиодов/м = 960 светодиодов
// Зона 2: 4 ленты × 5м × 60 светодиодов/м = 1200 светодиодов
// Зона 3: 4 кольца × 12 светодиодов = 48 светодиодов
// Итого: 2208 светодиодов
#define TOTAL_LEDS 2208

// Количество зон освещения
#define NUM_ZONES 3

// Пин подключения данных ленты (настраивается для каждого ESP32)
#define LED_PIN GPIOxx  // Замените GPIOxx на нужный пин

// Конфигурация зон
struct ZoneConfig {
  const char* name;      // Название зоны (редактируемое)
  uint16_t startLed;     // Начальный светодиод зоны
  uint16_t ledCount;     // Количество светодиодов в зоне
  bool hasDisplay;       // Наличие дисплея для часов
};

// Пример настройки зон для проекта HomeLight
ZoneConfig zones[NUM_ZONES] = {
  {"Барная стойка", 0, 960, true},    // Зона 1: 4 параллельные ленты по 4м (960 светодиодов), с дисплеем
  {"Над диваном", 960, 1200, false},  // Зона 2: 4 полосы по 5м (1200 светодиодов)
  {"Центральная", 2160, 48, false}    // Зона 3: 4 кольца по 12 светодиодов (48 светодиодов)
};

// === КОНЕЦ НАСТРАИВАЕМЫХ ПАРАМЕТРОВ ===
```

> **Важно**: Все числовые значения в примере (количество лент, длина, плотность светодиодов, число колец) приведены для иллюстрации конкретной конфигурации и могут быть заменены на любые другие. Система спроектирована так, что все параметры являются редактируемыми величинами.

### Детальное описание зон проекта

#### Зона 1 - Барная стойка
- **Контроллер**: ESP32 (выделенный)
- **Конфигурация**: 4 параллельные адресные ленты WS2812B
- **Длина каждой ленты**: 4 метра
- **Плотность светодиодов**: 60 шт/метр
- **Общее количество светодиодов**: 4 × 4м × 60 = 960 светодиодов
- **Особенности**: 
  - Возможность управления каждой лентой отдельно или совместно
  - Интегрированный дисплей для отображения часов
- **Гибкость**: Названия, количество лент, длина и плотность светодиодов - редактируемые параметры

#### Зона 2 - Над диваном
- **Контроллер**: ESP32 (выделенный)
- **Конфигурация**: 4 световые полосы адресных светодиодов WS2812B
- **Длина каждой полосы**: 5 метров
- **Плотность светодиодов**: 60 шт/метр
- **Общее количество светодиодов**: 4 × 5м × 60 = 1200 светодиодов
- **Особенности**: Равномерная подсветка большой площади
- **Гибкость**: Все количественные показатели могут быть изменены под конкретную задачу

#### Зона 3 - Центральная
- **Контроллер**: ESP32 (выделенный)
- **Конфигурация**: 4 декоративных кольца
- **Количество светодиодов в кольце**: 12 адресных светодиодов WS2812B
- **Общее количество светодиодов**: 4 × 12 = 48 светодиодов
- **Особенности**: Компактные световые элементы для акцентного освещения
- **Гибкость**: Количество колец и светодиодов в каждом кольце - настраиваемые величины

### Рекомендации по настройке

1. **Определение зон**: Разделите пространство на логические зоны (например, "Барная стойка", "Над диваном", "Центральная")
2. **Расчет светодиодов**: Подсчитайте количество светодиодов для каждой зоны
3. **Настройка в коде**: Внесите данные в массив `zones[]` для каждого ESP32
4. **Тестирование**: Проверьте работу каждой зоны отдельно перед объединением в сценарии

> **Важно**: Все числовые значения в проекте являются редактируемыми величинами и могут быть изменены в соответствии с вашей конфигурацией.
